Introduction

Selene is a documentation toolkit for people who would rather write than configure. Compose the blocks you need, keep the theme you love, and publish from any React framework, CMS, or plain folder of Markdown.

Selene is a React documentation toolkit for writers and engineers, crafted in the open. Powerful features for your docs workflow, deep customizability for your taste, and it plays nicely with any framework, CMS — anything.

Try it out
pnpm create selene-app 📋

Anybody can write.

Native support for Markdown and MDX, with an intuitive, extensive syntax for non-dev writers, developers, and documentation agents alike.

Writer→Developer→Automation
📋
--- title: Hello Moon --- ## Overview I love **Selene**! ```ts tab="Tab 1" console.log("Hello Moon") ```

The familiar syntax.

It is just Markdown, with additional features composing seamlessly into the syntax.

  • Markdown features, including images
  • Syntax highlighting with zero config
  • Codeblock groups and tabs
  • Callouts, cards, and steps
  • Custom heading anchors
  • Automatic table of contents

Docs for engineers.

A truly composable toolkit.

Separated as Content → Core → UI, offering the composability engineers love. Use Selene as a library, without adopting an entire framework.

selene-mdxUse Markdown elegantly in any React setupcontent
selene-coreHeadless library for docs structure and searchcore
selene-uiThe themed interface, ready to shipinterface
selene-openapiRender living API references from a specextension

Adopts your content.
