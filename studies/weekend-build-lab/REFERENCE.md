Captured 19 Sep 2026 from https://www.outskill.com/ (live production, desktop 1280px and mobile 390px viewports).

## What the page is

Sales landing page for a free 2-day live "Generative AI Mastermind" workshop. Pure conversion machine for a time-bound cohort offer.

## Observed tokens

- Background: near-black (~#0a0a0a), cards ~#16161a, borders ~#2a2a2e.
- Accent: chartreuse/lime (~#c9f24b) used ONLY for CTAs and tiny highlights.
- Light sections: pure white background, black text, hairline borders (#e5e5e0).
- Type: neutral grotesque; hero ~60-66px/1.05 tight tracking; eyebrows 12px uppercase tracked wide (not mono on source, mono works equally well).
- CTA shape: soft rectangle (~8px radius), not a full pill.
- Photos: all desaturated/grayscale so the lime owns attention.

## Interaction patterns

- Schedule: left list drives right detail panel (tab pattern), active row darker.
- FAQ: accordion, plus rotates to x.
- Sticky bar: blurred dark, persistent, real countdown.
- Carousels: arrow-controlled, no autoplay observed.

## What the study changes (originality)

- New fictional brand ("Weekend Build Lab"), original copy throughout, fictional stats/dates/backers/testimonials/logos.
- Photography replaced with generated CSS scenes (layered gradient ridges, grain, glow) and CSS-drawn card visuals.
- Keeps the system: dark cinematic hero + stat row, trust wall, logo strip, program cards, light schedule switcher, testimonial grid, split FAQ, sticky conversion bar with countdown, single lime accent.
