# Reference notes - raycast.com

Source observed: https://www.raycast.com/ on 2026-09-19 IST.

## What defines the system

- Near-black page (`#07080a`) with white type, restrained gray copy, and thin cool-gray borders.
- Floating, blurred navigation inside a large rounded rectangle.
- Cinematic hero: oversized centered heading over diagonal red light bands and a deep black vignette.
- Product proof is the visual language. Dark launcher windows, command rows, keyboard caps, clipboard snippets, and extension tiles explain the product without long copy.
- Headings use tight tracking and medium weight. The hero is about 64px at a 1440px viewport; later display headings range from 56px down to compact 20-32px section titles.
- Long landing rhythm alternates open editorial statements with contained product cards.
- Accent color is mostly red/coral, backed by occasional blue, green, yellow and violet application colors.
- Buttons are light, compact, and tactile against the dark environment.
- Mobile should retain the cinematic hero and product windows, collapse navigation, stack cards, and shorten command lists.

## Study substitutions

The runnable study is named **Keystroke** and uses original copy, a CSS-only diamond mark, generated gradient light bands, authored launcher mockups and generic extension tiles. It does not copy Raycast's brand mark, screenshots, app icons, imagery, fonts or product copy.
