FAQs

Questions, answered

Is Atlas UI React really open source?+
Yes. The core library is MIT-licensed. Paid tiers add premium components, page examples, and team features on top of the same base.
Does it include a CLI tool?+
Yes. The CLI scaffolds a project, installs only the components you pick, and keeps them up to date with a diff-friendly format.
Is dark mode supported?+
Every component is themed through CSS variables. Toggle a single class on the root element to switch palettes.
Can I use it in commercial projects?+
The free tier covers commercial use for one user. Team use across a company needs a Pro Team license.
