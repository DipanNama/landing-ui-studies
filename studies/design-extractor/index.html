Questions? Answers.

Everything you need to know about Spectra.

What exactly does Spectra do?+

Spectra turns any live page into an inspectable design reference. It reads colors, fonts, spacing and layout, lists every asset on the page, and can generate a complete exportable design system in one click.

Do I need to know DevTools?+

No. Spectra is built so you never open DevTools. Click any element and its styles, colors, fonts and spacing appear in plain language.

What can I extract?+

Every visual asset on the page: images, SVG graphics and icons, videos with poster frames, and Lottie animations. Download them individually or as one zip.

How does the design system export work?+

One click analyzes the whole page and produces color scales, a type scale, radius and shadow tokens. Export to CSS variables, SCSS, a utility config, or JSON.

Does my browsing data leave my machine?+

No. All inspection and extraction runs locally in your browser. Page content is never sent to a server.

What is a page snapshot?+

A snapshot saves the current page as a single self-contained HTML file with styles inlined and images embedded, so you can reference it offline.
