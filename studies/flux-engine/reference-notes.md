# Reference notes - vite.dev

Source reviewed: https://vite.dev/ on September 19, 2026 (IST).

## Observed visual system

- Near-black canvas with thin cool-gray borders dividing major regions.
- Slim gradient announcement ribbon above an 80px utility navigation.
- Hero is a two-column frame: oversized left-aligned product statement and a large abstract 3D product mark.
- Restrained purple/blue/orange glow is used as a directional accent, not as a background wash.
- Primary and secondary actions are compact rounded rectangles; primary has a purple outline/glow rather than a filled brand block.
- Package-manager switcher sits inside a dark terminal block beneath the hero copy.
- Desktop page uses explicit frame lines and paired feature cells. Mobile collapses copy and visual into stacked, centered blocks and reduces navigation to logo, search and menu.
- Below the fold: trust logo strip, benefit pairs with technical visuals, framework/tool ecosystem, community proof, open-source sponsor area, and a focused final CTA.

## Measurements captured

- Desktop viewport: 1280 x 720; page height about 6,792px.
- Mobile viewport: 390 x 844; page height about 9,944px.
- Desktop hero heading visually about 60-64px; mobile about 38-40px.
- Base surfaces around #121318, borders around #30313a, body copy around #a6a7b1.
- Major desktop sections use about 96-112px vertical padding; mobile about 72-84px.

## Original-study substitutions

This study is named Flux. It uses original copy, a CSS-authored geometric mark, generic fictional company names, abstract CSS feature diagrams and fictional community quotes. No Vite logo, source media, partner marks, testimonials, brand copy or proprietary assets are included.

## Comparison checklist

- Dark technical frame and line rhythm preserved.
- Desktop split hero and mobile centered stacked hero preserved.
- Package-manager tab interaction implemented with original commands.
- Abstract 3D feel recreated entirely in CSS.
- Trust, benefits, ecosystem, proof and final CTA maintain the source page's pacing while using original content.
